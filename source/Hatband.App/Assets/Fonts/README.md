# Library title fonts

The application bundles these static font files from the official
[Google Fonts repository](https://github.com/google/fonts):

| Style | Font | Weight | Source |
| --- | --- | --- | --- |
| Cinema | Bebas Neue | Regular (400) | [Bebas Neue](https://github.com/google/fonts/tree/main/ofl/bebasneue) |
| Futuristic | Rajdhani | SemiBold (600) | [Rajdhani](https://github.com/google/fonts/tree/main/ofl/rajdhani) |
| Editorial | Spectral | SemiBold (600) | [Spectral](https://github.com/google/fonts/tree/main/ofl/spectral) |
| Light | Lato | Light (300) | [Lato](https://github.com/google/fonts/tree/main/ofl/lato) |

Each font directory contains its original SIL Open Font License in `OFL.txt`.
Font files are embedded by the existing `Assets/**` Avalonia resource rule.
